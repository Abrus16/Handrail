# Handrail website

One-page site. Everything is in `index.html`.

Before launch, replace the placeholders in square brackets inside `index.html`
(search for `[`): founder photos, Abraham's one-line bio, business email,
and the registered company details in the footer.

The contact form uses Netlify Forms. After the first deploy, turn on form
detection in the Netlify dashboard (Forms), then redeploy.
